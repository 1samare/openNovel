# tests/ui 目录说明

## 目录用途

存放由 Vitest、Vue Test Utils 和 happy-dom 执行的 Vue 组件测试及其专用夹具和初始化代码。

## 内容说明

- `setup.ts`：注册每个测试结束后的 Vue wrapper 自动卸载。
- `ComponentHarness.vue`：验证 Vue 单文件组件编译和 DOM 挂载的最小测试夹具。
- `component-harness.spec.ts`：验证组件渲染结果和 happy-dom 环境可用。
- `project-center.spec.ts`：挂载真实项目中心，验证 loading/empty、显式表单标签、重复提交锁、最近项目、缺失路径、错误恢复和成功导航。
- `workspace-project-actions.spec.ts`：挂载真实工作台布局，验证当前项目的重命名、备份、关闭前编辑器刷盘、命令锁、错误反馈、工作区内品牌导航与无活动项目禁用状态。
- `chapter-editor-session.spec.ts`：验证 800ms 自动保存、并发 flush 串行化、章节切换与窗口退出前强制刷盘、保存冲突与正文可恢复状态。
- `chapter-editor-view.spec.ts`：挂载真实章节页面和 CodeMirror 编辑器，验证章节树、中文组合输入、选区回调、搜索、全屏、只读历史、版本、导入预览确认与三种导出入口。
- `model-settings.spec.ts`：挂载真实模型设置页，验证脱敏密钥、DeepSeek 预设、连接测试取消、手工模型 ID、档案范围与能力、三模式六角色绑定、跨供应商确认和无配置阻断。
- `novel-bible.spec.ts`：挂载小说圣经控制器、共享提案审阅和世界观/人物/大纲页面，验证跨项目陈旧响应、命令锁、严格 draft、结构化字段/关系人物、失败表单与档案 dirty 草稿保留、候选与历史快照预览、恢复确认、四级树与局部候选。

## 依赖边界

本目录只依赖测试期 Vue、Vitest、Vue Test Utils 和 happy-dom；不得导入 Electron 主进程、真实文件系统、网络服务或模型 Provider。

## 维护规则

测试应断言用户可观察的 DOM 或组件输出，并在新增文件或改变测试入口时同步更新本 README 和父级 `tests/README.md`。
