# preload 目录说明

## 目录用途

存放 Electron 预加载脚本和受控的页面桥接代码。

## 内容说明

- `index.ts`：仅在上下文隔离开启时暴露命名的 Agent、Project、Chapter、Model 与保存生命周期桥接。
- `agent-api.ts`：将八个命名 Agent 方法映射到固定 IPC 通道；只向回调交付校验且克隆后的 Agent 事件。
- `project-api.ts`：将九个命名项目方法映射到固定 IPC 通道，并按命令拒绝畸形结果或成功载荷。
- `chapter-api.ts`：将十三个命名章节、版本和文件交换方法映射到固定 IPC 通道，并逐命令拒绝畸形结果。
- `model-api.ts`：将九个命名模型方法映射到固定 IPC 通道，并按连接、测试、列表、Profile 与绑定类型拒绝畸形或含密钥结果。
- `renderer-flush-api.ts`：只监听固定保存请求并回传布尔结果；不向页面暴露通用 IPC。

## 依赖边界

预加载层不得向页面暴露通用 Electron、Node.js、IPC 或文件系统能力；新增桥接必须使用白名单和共享类型。

## 维护规则

修改预加载代码时，必须同步更新本 README，并同时更新相应的安全契约测试。
