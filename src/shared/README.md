# shared 目录说明

## 目录用途

存放可由 Electron 主进程、预加载层和渲染进程共同使用的纯类型与常量。

## 内容说明

- `app.ts`：应用级共享常量和类型。
- `agent.ts`：Agent Run 状态、六种可重试性明确的错误、十二种带公共字段的事件、分阶段输出/恢复检查点、Run 加载诊断/列表结果和 `data` 结果分支的纯公共契约。
- `agent-ipc.ts`：固定 Agent 命令/事件通道、每个命令的运行时参数校验，以及由预加载和渲染层复用的最小 `AgentApi` 类型。
- `project.ts`：阶段 1 项目 manifest/摘要/最近项目、结果/错误、九个固定 IPC 通道、参数守卫、逐命令成功载荷守卫与最小 `ProjectApi` 纯契约。
- `chapter.ts`：阶段 2 章节、草稿、版本、导入预览、导出快照、十三个固定 IPC 命令与最小 `ChapterApi` 公共契约、严格响应守卫及统一 Unicode 正文字数统计。
- `model.ts`：阶段 3 Provider、模型档案、角色/模式绑定、Zod 运行时结构、Model Gateway、稳定错误、九个固定 IPC 命令、脱敏结果守卫与最小 `ModelApi` 公共契约。
- `novel.ts`：阶段 4 题材、小说圣经资料/大纲/版本/提案、档案乐观版本输入、显式恢复来源、人物关系最小约束、三角色严格 Zod 输出、十个固定 Bible IPC 命令、公开载荷/结果守卫与最小 `NovelBibleApi` 公共契约。
- `renderer-flush.ts`：定义退出前编辑器保存握手的两个固定事件、UUID 请求守卫和最小生命周期桥接。

## 依赖边界

本目录不得依赖 Electron、Node.js、Vue 或任一运行时专有模块；模型结构契约可使用跨进程通用的 Zod 类型，但不得引入任一供应商 SDK。

## 维护规则

修改共享契约时，必须同步更新本 README，并同步检查所有消费方的类型与行为测试。
