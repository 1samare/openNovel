# shared 目录说明

## 目录用途

存放可由 Electron 主进程、预加载层和渲染进程共同使用的纯类型与常量。

## 内容说明

- `app.ts`：应用级共享常量和类型。
- `agent.ts`：Agent Run 状态、六种可重试性明确的错误、十二种带公共字段的事件、分阶段输出/恢复检查点和 `data` 结果分支的纯公共契约。

## 依赖边界

本目录不得依赖 Electron、Node.js、Vue 或任一运行时专有模块，以保持跨进程可复用性。

## 维护规则

修改共享契约时，必须同步更新本 README，并同步检查所有消费方的类型与行为测试。
