# renderer 目录说明

## 目录用途

存放 Electron 渲染进程的 HTML 入口和 Vue 应用源码。

## 内容说明

- `index.html`：带有限制性内容安全策略的渲染入口。
- `src/`：Vue 应用、路由、样式和页面实现。

## 依赖边界

本目录运行在受隔离的浏览器环境中，不得直接使用 Node.js 或 Electron API；仅能使用受控预加载桥接。

## 维护规则

修改渲染入口或 Vue 应用时，必须同步更新本 README 及受影响子目录 README。
