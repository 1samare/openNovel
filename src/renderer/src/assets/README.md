# assets 目录说明

## 目录用途

存放 Vue 渲染应用共享的静态样式资源。

## 内容说明

- `base.css`：应用基础颜色、排版和布局样式；包括项目中心、工作台项目操作、模型设置的暖纸色语义令牌、响应式卡片/表单/反馈状态，以及 Harness Agent 的 Prompt/Run 工作区样式。

## 依赖边界

本目录只包含由渲染层引用的静态资源，不包含业务状态、Electron API 或构建产物。

## 维护规则

修改共享样式时，必须同步更新本 README；样式应保持与组件语义和响应式布局一致。
