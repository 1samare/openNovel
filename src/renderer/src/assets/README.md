# assets 目录说明

## 目录用途

存放 Vue 渲染应用共享的静态样式资源。

## 内容说明

- `base.css`：应用基础颜色、排版和布局样式，以及 Harness Agent 的暖纸色语义令牌、Prompt/Run 错误状态、响应式工作区和可访问交互状态；520px 以下顶栏 secondary link 保持 44px 居中命中区且不触发横向溢出。

## 依赖边界

本目录只包含由渲染层引用的静态资源，不包含业务状态、Electron API 或构建产物。

## 维护规则

修改共享样式时，必须同步更新本 README；样式应保持与组件语义和响应式布局一致。
