# model 目录说明

## 目录用途

存放渲染进程的模型连接、模型档案与项目角色路由状态协调逻辑。

## 内容说明

- `use-model-settings.ts`：通过受限 `window.openNovel.models` 桥接加载和保存脱敏连接、档案与绑定，并协调连接测试取消、模式/角色能力门禁、供应商类型级跨供应商确认，以及原生 Provider 可留空 Base URL 的表单校验。

## 依赖边界

本目录只依赖 Vue 响应式能力、共享模型公开类型与九方法 Model API；不得导入 Electron、Node.js、数据库、密钥存储或 Provider SDK。

## 维护规则

密钥只能存在于当前表单的短生命周期字段，成功提交后立即清空；公开状态和错误文案不得保存或回显密钥及底层 Provider 详情。改变模型设置行为时必须同步 UI 测试与本 README。
