# layouts 目录说明

## 目录用途

存放 Vue 工作台的页面布局组件。

## 内容说明

- `WorkspaceLayout.vue`：承载导航、内容区域与当前项目重命名/备份/关闭操作的工作台布局。

## 依赖边界

布局组件依赖 Vue Router 与渲染层项目状态控制器；不得直接访问 Electron、Node、文件系统或 SQLite。

## 维护规则

修改布局结构时，必须同步更新本 README，并验证导航、内容区域和可访问性不受破坏。
