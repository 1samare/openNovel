# views 目录说明

## 目录用途

存放由 Vue Router 直接渲染的工作台页面组件。

## 内容说明

- `ProjectCenterView.vue`：本地优先项目中心，提供新建、打开、最近项目恢复与仅移除记录入口。
- `WorkspacePlaceholderView.vue`：各一级模块的占位页面。
- `AgentHarnessView.vue`：AI 对话的离线 Agent Run 创建、审批、时间线、错误和恢复页面，包含 Prompt 错误恢复、状态播报、流式 final 与失败 Run 诊断。
- `ChapterEditorView.vue`：可选择和维护分卷/章节层级的章节树、正文编辑、自动保存状态、版本恢复、导入预览确认和整书导出的三栏工作台页面。
- `ModelSettingsView.vue`：按连接、模型档案、项目角色绑定逐步呈现 BYOK 设置，包含 DeepSeek 预设、连接测试取消、手工能力声明、模式/角色能力不足选项禁用、原生 Provider 默认端点与跨供应商显式确认。
- `WorldBibleView.vue`：作品方向、两类题材模板、档案 CAS/历史、未保存草稿隔离、六类世界资料、设定候选审阅和带快照预览/确认的历史恢复页面。
- `CharacterBibleView.vue`：人物档案、受人物引用约束的关系/阶段状态、人物候选审阅和带快照预览/确认的历史恢复页面。
- `OutlineBibleView.vue`：总纲/分卷/阶段/章节规划树、参与人物、键盘排序、局部剧情候选和带快照预览/确认的历史恢复页面。

## 依赖边界

页面组件可依赖 Vue、路由参数和受控应用接口，不应直接使用 Node.js、Electron 或未授权的持久化能力。

## 维护规则

修改页面功能时，必须同步更新本 README，并增加或调整可观察的渲染契约测试。
