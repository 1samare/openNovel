# editor 目录说明

## 目录用途

存放章节编辑会话、自动保存和工作区关闭前刷盘协调逻辑。

## 内容说明

- `use-chapter-editor.ts`：加载章节、维护草稿 revision、800ms 防抖自动保存并处理切换、保存冲突及章节树节点重命名、移动和删除。
- `workspace-flush.ts`：集中登记活动编辑器，在路由离开、备份、关闭项目或窗口前等待未保存正文刷盘。

## 依赖边界

只依赖 Vue 响应式能力和共享 `ChapterApi` 类型，不直接访问 Electron、Node.js、文件路径或数据库。

## 维护规则

修改保存时序时必须覆盖定时器、并发保存、章节切换、失败保留正文和关闭前刷盘测试。
