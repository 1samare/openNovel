# renderer/src 目录说明

## 目录用途

存放 Vue 渲染应用的启动入口、组件、样式、导航和路由。

## 内容说明

- `main.ts`：Vue 应用启动入口，并响应主进程退出前保存请求，等待全部活动编辑器刷盘后回传结果。
- `App.vue`：应用根组件。
- `assets/`：全局样式资源。
- `layouts/`、`navigation/`、`router/`、`views/`：工作台界面组织代码。
- `components/`：可复用 Vue 组件，包括 CodeMirror 6 章节正文编辑器。
- `editor/`：章节编辑会话、800ms 自动保存与关闭前刷盘协调逻辑。
- `agent/`：Harness Agent 的事件合并、回补、失败详情回读、异步代际、命令锁和操作重试协调逻辑。
- `project/`：项目中心与工作台的最近项目、新建、打开、恢复、重命名、备份、关闭和错误反馈状态协调逻辑。
- `env.d.ts`：渲染进程类型声明，包括受限的 Agent、九方法 Project、十三方法 Chapter 与双方法生命周期桥接类型。

## 依赖边界

代码依赖 Vue 和 Vue Router；不得绕过预加载安全边界访问 Electron 或 Node.js。

## 维护规则

修改任一子目录时，必须同步更新对应 README；页面可见功能变化需同步更新相关测试和根目录说明。
