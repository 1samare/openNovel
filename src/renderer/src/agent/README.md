# renderer/src/agent 目录说明

## 目录用途

存放 Harness Agent 工作台的渲染层状态协调逻辑。

## 内容说明

- `use-agent-harness.ts`：订阅受控 Agent API、合并 Run 快照和事件、回补序列缺口；连续 `run.failed` 合并后会以既有代际保护回读持久化的安全错误详情，并提供带命令锁、finally 释放和操作级重试的创建、审批、取消和恢复命令。

## 依赖边界

此目录仅依赖 Vue 响应式能力与 `@shared` 的 Agent 公共类型；不得导入 Electron、Node.js 或绕过 `window.openNovel.agent` 的预加载边界。

## 维护规则

事件必须按 Run 和序列去重、排序，单项事件失败不得阻断队列；连续失败事件合并后必须刷新持久化 Run 详情且可重试；加载/刷新结果必须受代际保护，命令必须在同步锁与状态门控下执行；新增状态转换或命令时同步更新行为测试与本 README。
