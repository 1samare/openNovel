# bible 目录说明

## 目录用途

存放 renderer 小说圣经的异步状态、命令锁、生成取消、提案决定与版本恢复协调逻辑。

## 内容说明

- `use-novel-bible.ts`：统一加载世界观、人物和大纲快照，以 revision 与 projectId 隔离陈旧加载/版本/生成响应，返回保存是否成功供页面保留失败表单，并协调提案生成/取消、决定与版本恢复。

## 依赖边界

本目录只依赖 Vue 响应式能力、共享小说契约和 `NovelBibleApi`；不得访问 Electron、Node.js、SQLite、路径或模型供应商对象。

## 维护规则

所有异步结果必须经过代次或命令锁保护；错误只显示 preload 返回的公开信息，页面不得自行推断数据库状态。
