保存 OpenNovel 多 Agent 小说创作助手从现有 Harness 基座推进到 Windows 可安装测试版的全阶段开发计划和后续实施记录。

## 内容说明

- `多Agent小说创作助手全阶段开发计划.md`：记录已确认产品决策、目标架构、公共契约、阶段任务、质量门禁和最终安装验收标准。

## 依赖边界

本目录只保存开发计划与验证记录，不存放运行时代码、API Key、第三方 Skill 包、构建产物或用户小说数据。

## 维护规则
