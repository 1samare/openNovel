# 小说 AI 辅助写作桌面端基础架构设计

## 目标

基于产品设计文档搭建一个能够在 Windows 本地启动的桌面应用骨架，为后续小说项目管理、AI 对话、世界观、人物、大纲和正文编辑等功能提供清晰边界。本阶段不实现业务逻辑、数据持久化、模型调用或应用内配置能力。

## 技术方案

- 桌面容器：Electron
- 前端框架：Vue 3
- 开发语言：TypeScript
- 构建工具：electron-vite
- 页面导航：Vue Router
- 包管理：npm

项目不预装状态管理、数据库、UI 组件库、富文本编辑器、AI SDK 或测试框架。只有在后续业务需求明确时再引入对应依赖。

## 进程架构

### Electron 主进程

`src/main` 负责应用启动、窗口创建、窗口生命周期和基础失败日志。主进程不包含项目、文档或 AI 业务逻辑。

### 预加载层

`src/preload` 是主进程与渲染进程之间的安全边界。本阶段不开放文件系统、网络请求或业务 IPC，只保留后续扩展所需的目录和类型入口。

Electron 窗口启用 `contextIsolation`，渲染进程禁用 `nodeIntegration`。

### Vue 渲染进程

`src/renderer` 包含 Vue 应用入口、路由、公共布局、基础样式和模块占位页面。渲染进程不直接访问 Node.js 或 Electron 主进程能力。

### 共享代码

`src/shared` 只放置主进程与渲染进程都可安全使用的纯 TypeScript 类型和常量。本阶段不定义业务实体或数据库模型。

## 页面与组件边界

基础骨架提供以下静态页面：

- 项目中心；
- 项目概览；
- AI 对话；
- 世界观；
- 人物；
- 大纲；
- 章节；
- Skill；
- 版本历史；
- 设置。

公共界面由侧边导航、顶部栏、内容容器和统一占位视图组成。页面之间只通过 Vue Router 切换，不提供新增、编辑、删除、保存、生成或配置等业务操作。

## 数据流

本阶段没有业务数据流：

1. Electron 主进程创建窗口并加载渲染页面；
2. Vue 应用启动并挂载路由；
3. 用户点击导航后，Vue Router 切换静态占位页面；
4. 主进程、预加载层和渲染进程之间不传输业务数据。

## 错误处理

- Electron 启动或页面加载失败时输出基础错误日志；
- Vue 注册全局错误处理入口并将未捕获错误输出到控制台；
- 本阶段不建立业务错误码、重试、通知或恢复机制。
