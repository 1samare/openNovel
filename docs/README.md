# docs 目录说明

## 目录用途

按执行日期归档架构设计、修改计划和验证结果，为人类开发者与 Harness Agent 提供可追溯的实施依据。

## 内容说明

- 日期目录统一使用 `YYYY-MM-DD`。
- 每项独立修改使用一份以 `计划.md` 结尾的实施计划。
- 架构设计与同一任务的计划、结果放在同一日期目录。

## 依赖边界

本目录只保存项目文档，不承载运行时代码、生成产物或本地密钥。

## 维护规则

新增或修改日期目录中的文档时，必须同步更新该日期目录的 `README.md`；修改本文件时同步更新根目录 `README.md`。
